# QuickMenu - macOS 原生访达（Finder）右键增强助手

参考“超级右键”开发的极简原生 macOS 右键增强工具，基于 Swift + FinderSync 扩展开发。纯本地原生运行，内存占用极低，深度融入 macOS 访达生态。

---

## ✨ 核心特性

### 1. 📄 极简“新建文件”菜单
彻底告别冗长的标题，采用与“超级右键”一致的简洁清爽风格，并带高清类型/应用图标：
- **TXT**：一键新建 `新建文本.txt`
- **Markdown**：一键新建 `未命名.md`
- **WPS 智能联动（检测到已安装 WPS 时自动呈现）**：
  - **WPS 文字**（新建并关联 WPS 文字文档）
  - **WPS 表格**（新建并关联 WPS 表格）
  - **WPS 演示**（新建并关联 WPS 演示幻灯片）
- **通用 Office**：
  - **Word**（新建 `.docx`）
  - **Excel**（新建 `.xlsx`）
  - **PPT**（新建 `.pptx`）
- **Apple iWork（检测到已安装 Pages/Numbers/Keynote 时智能显示）**：
  - **Pages** / **Numbers** / **Keynote**
- **自定义模板**：
  - 点击「📂 打开模板文件夹...」，放入任何你经常使用的模板（合同、模板代码、特定表格等），右键将自动动态加载！

### 2. 🚀 快捷打开方式（已量身适配你的工具链）
每个项均带有该 App 的原生高清图标：
- **Wave 终端**：快速在当前路径打开 Wave 终端
- **VS Code**：快速用 VS Code 打开当前文件或项目
- **PyCharm**：快速用 PyCharm 打开工程
- **系统终端**：快速启动系统原生 Terminal 并自动 `cd`

### 3. 📋 拷贝路径
- **绝对路径**：多选时自动换行拼接绝对路径
- **文件名**：仅拷贝文件名及扩展名
- **终端转义路径**：路径带空格或特殊符号时自动转义为 `\ `，终端粘贴直接执行

### 4. ✂️ 剪切、移动与复制文件体系
- **智能场景识别**：在空白处右击绝不出现「剪切」，仅当选中具体文件/文件夹时才显示「✂️ 剪切 X 项」
- 当剪切板中有待移动文件时，在目标目录右击才呈现「📌 移动 X 项到此处」
- **📦 移动文件到** >（选中文件时显示）
  - 二级菜单直达常用系统目录：**下载 / 图片 / 音乐 / 影片 / 文稿 / 自定义路径...**
  - 点击“自定义路径...”可唤起原生文件夹选择器，随心选择目标位置！
- **📑 复制文件到** >（选中文件时显示）
  - 同样直达：**下载 / 图片 / 音乐 / 影片 / 文稿 / 自定义路径...**
- 移动/复制完成后自动在访达中高亮选中新文件，并自带防重名冲突保护！

### 5. 🗜️ 压缩与解压缩体系
- **当在压缩文件（.zip, .tar, .gz, .tgz, .7z, .rar 等）上右键时**：
  - **📂 解压到当前文件夹**：将包内内容直接解压到当前目录，并自动在访达中高亮解压出的所有文件。
  - **📁 解压到单独文件夹**：自动以压缩包名新建独立同名文件夹并解压入内，自动防重名，解压完成自动在访达定位高亮该文件夹！
  - **🗑️ 解压到单独文件夹并删除原压缩包**：解压完成后自动将原压缩文件安全移入废纸篓（支持撤销防误删）。
  - **🗜️ 自定义压缩...**：一键唤起原生弹窗，支持设置压缩名、选择格式（.zip / .tar.gz）及设置密码加密！
- **当在普通文件/文件夹上右键时**：
  - **🗜️ 压缩为 ZIP**：快速一键打包为 `.zip`。
  - **🗜️ 自定义压缩...**：弹窗自定义文件名、格式与可选密码。
- **空白处自动隐藏**：在空白处右键绝不显示任何多余的解压/压缩选项，保持极端干净。

### 6. 🎨 紧凑优雅的菜单体验
- 一级菜单项之间、二级菜单项之间均去除无意义的空行/分割线，紧凑连贯，与 macOS 原生体验完全一致
